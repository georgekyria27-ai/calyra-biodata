Quality control

Process instead of promises

Anyone can produce a p-value. The value is in being able to defend how it was produced six months later.

  1. A written analysis plan before anyone touches data

    Hypotheses, endpoints, statistical methods and figure list agreed in writing first. It prevents the common failure where methods get chosen after seeing the result.

  2. Reproducible code with every deliverable

    Commented R, Python or SAS scripts that regenerate every table and figure from the raw input. You keep them, with no licence strings attached.

  3. Independent peer review on high-stakes work

    Anything heading for a regulator, a sponsor or a publication is checked by a second qualified analyst before it reaches you.

  4. A deliverable checklist before anything ships

    Version, data provenance, method statement, assumption checks, figure legends and file formats verified against a fixed list. Every time.

Straight answers

Questions labs ask first

Do you run any physical lab work?

No. Calyra BioData is a dry-lab practice — we work only with data you already have or are about to generate. There is no wet-lab testing, no sample handling, and no diagnostic interpretation.

What does a first project usually look like?

Most labs start with the four-week Lab Data Reporting & QC Sprint at C$4,500–C$5,500, or a smaller one-off data audit from C$1,500. Both are fixed-scope and fixed-price, so you know the number before we begin.

Who actually does the analysis?

Projects are scoped and quality-controlled in-house and delivered with vetted independent specialists — biostatisticians for clinical-style analysis, bioinformaticians for sequencing work. You are told who is on your project before it starts.

Will we be able to reproduce the results ourselves?

Yes. Every engagement ships with the commented R, Python or SAS scripts that generated the figures and tables, plus a written methods section. Nothing lives only on our machines.

What are your turnaround times?

One-off audits run one to two weeks. Dashboard and QC-reporting sprints run three to four weeks. Larger multi-source projects run six to ten weeks. Timelines assume complete data within five business days of kickoff.

Tell us where your lab data gets stuck.

A 30-minute scoping call. We map your data flow, name the bottleneck, and tell you plainly whether this is worth paying for.
